# 鏡の映り込み

`CLAUDE.md` から移した機能ごとのメモ。**規則と同じ効力を持つ。** この領域を触る前に読み、分かったことはここに書き足す。

### 鏡の映り込み

`Reflector` はファインダーとパースの 2 つで有効。1 枚につきシーンをもう 1 度描くので、
置いた枚数ぶん重くなる（swiftshader の実測で 2 枚 16.5 ms/frame、実 GPU ならもっと軽い）。
描画は必要なときだけ走る作りなので、置きっぱなしでも常時は食わない。

**映り込みには寸法リボン・撮影範囲・マニピュレータを入れない。** 図面の上書きであって
現場には無いものなので、`onBeforeRender` を包んで一時的に隠している。

**同じところで壁の不透明さも元に戻す。** パースでは視点の外側にある壁を
`opacity 0.22` にしているが、鏡の仮想カメラは別の位置から見ている。そのまま描くと
鏡が半透明の壁を透かして外の暗い空間を映し、映り込みが暗く沈む。

**「鏡が部分的に映らない」の正体は、たいてい映り先が真っ黒なこと。** 実際に 3 つあった。

1. **天井の裏。** 天井は下向きにしか面が無く、太陽もヘミライトの空側も当たらないので
   ほぼ黒だった。床鏡は真上を映すので、鏡が黒く抜けて見えた。`matCeil` に
   `emissive` を持たせて灰色を保っている。**天井の色を暗く戻さないこと。**
2. **スタジオに前壁が無い。** 前（+Z）を向いた鏡と、浅い角度の床鏡は、
   何も無い方向を映してアプリの暗い地色を出していた。映り込みのあいだだけ
   `scene.background` を明るいスタジオ色（`REFLECT_BG`）に差し替えている。
3. **床鏡が床の裏側を映していた。** 床鏡は床の 1 cm 上にある。`Reflector` の
   斜め near クリップ（`clipBias` 0.003）ではその 1 cm を切り分けられず、
   仮想カメラが床の裏（光の当たらない面＝黒）を見ていた。**床鏡の映り込みのあいだは
   床と grid・外周線を消す**（`userData.ground`）。壁鏡は床を映してよいので消さない。

どれも「反射が動いていない」ではなく「反射先が黒い」だった。次に同じ相談が来たら、
まず映り先の面に色を付けて（例えば天井を赤くして）鏡に出るか確かめること。

**`readRenderTargetPixels` で反射の中身は覗けない。** three の `Reflector` は
HalfFloat かつマルチサンプルのターゲットを使うので、`Uint8Array` に読み出すと
全部 0 になる。中身を見たいなら別の手を考えること（これで 1 度、
「反射が真っ黒だ」と誤診した）。

鏡どうしの無限反射は three の `Reflector` 側で止まる（自分を隠してから描くため）。
