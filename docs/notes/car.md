# 車

`CLAUDE.md` から移した機能ごとのメモ。**規則と同じ効力を持つ。** この領域を触る前に読み、分かったことはここに書き足す。

### 車

**積み木の車は廃止した。** 寺村さん本人が用意した GLB（Tripo）を置いている。
人物モデルと同じで、**全長 1 m・車首 +Z・接地 y=0** に揃えて `models/car-<id>.glb`。
登録は `CAR_MODELS` に 1 行（`id` / `label` / 実車の `size` = w, d, h）。
`+` の「車」は既定のセダンを置き、車種は設定パネルのサムネイルで選ぶ
（人物と違って**後から差し替えてよい** — 車は「誰か」ではないので）。

**モデルは実車の w × d × h へそのまま合わせる（等倍にしない）。** 元データの比率は
実車と少しずれていて、全長 4.7 m に等倍で合わせると全幅が 2.1 m になる。
図面としては**平面の大きさが正しいほうが効く**ので、非等倍で入れている。
歪みは 1 割ほどで、見て分かるものではない。

**色は持たせない。** モデルに塗りが焼いてある。テクスチャごと乗算で染めると
窓もライトも同じ色になるので、色のプリセットは外した。

**「モダン」は消した。** テクスチャの入っていないものを間違って入れてしまっていたので、
その席に SUV を入れた（寺村さんの指摘）。id は `modern` ではなく `suv`。

古いリンクの `wagon` / `van` / `kei` / `modern` は `migrate()` がセダンに寄せる。
**そのとき w/d/h は触らない** — リンクに入っている寸法がその現場の図面なので、
車種の見た目だけ置き換えて大きさは残す。バンのモデルが入ったら `CAR_MODELS` に
足して、移行の行き先をそちらへ変える。

サムネイルは `tools/make-thumbs.mjs` が `car-` で始まるファイルを横長（200×140）で
斜め前から撮る。真横だとどれも同じ影絵になって選べない。

#### 窓のガラス

**車内からガラス越しにグリーンバックを撮る**、は現場でふつうにある画。そのためには
モデルの窓が**透過するマテリアル**になっている必要がある。`markGlass()` が
`parseModel()` の出口で見ていて、同梱モデルにも取り込んだモデルにも同じように効く。

窓として扱うのは次のどちらか。

- マテリアル名に `glass` / `window` / `windshield` / `windscreen` / `ガラス` / `窓`
- または書き出し側が `alphaMode: BLEND` で不透明度を落としている（その値を尊重する）

どちらでもなければ**窓かどうかは分からない**。**形やテクスチャの色から当てようとしないこと。**
実素材（Tripo）で両方試したが、車体・タイヤ・グリル・焼き込みの陰影と混ざって
分けられなかった。高さ帯 × 面の向き、高さ帯 × 明るさ、どちらにも山が立たない。
書き出し側でマテリアルを分けてもらうのが唯一の道。

**窓がガラスになっていないモデルの中にカメラが入ったら、そのカメラの絵からだけ外す**
（`shellsAround()`）。殻だけのスキャンモデルは中に入ると**画面が真っ黒になるだけ**で、
何の役にも立たない。自分の三脚を自分の絵から外しているのと同じ理屈。
**ガラスの入ったモデルが来たら、この規則はひとりでに効かなくなる**（`hasGlass()` で
判定しているので）。**その説明はパネルに出さない**（寺村さんの指摘） — 車種を選べば
数字が変わるのは見れば分かるし、窓の話はその車をファインダーに入れて初めて効く。
