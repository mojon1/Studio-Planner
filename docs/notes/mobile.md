# スマホ・タブレット（指で触る端末）

`CLAUDE.md` から移した機能ごとのメモ。**規則と同じ効力を持つ。** この領域を触る前に読み、分かったことはここに書き足す。

### ホーム画面から起動したときのノッチとホームバー

iPhone にホーム画面から入れると、`viewport-fit=cover` と
`apple-mobile-web-app-status-bar-style: black-translucent` で**画面いっぱい**に広がる。
何もしないと上のビューボタンがノッチの下に潜って押せない。

**ブラウザで開いたときの位置は変えない。** `:root` の `--sat/--sar/--sab/--sal` は
既定 0 で、`@media (display-mode: standalone)`（と古い iOS 用の `html.pwa`、
`navigator.standalone` で JS が付ける）のときだけ `env(safe-area-inset-*)` を入れる。
浮いている UI はすべて `calc(元の値 + var(--…))` で置く。

**ビューは、パネルが接している辺の余白を取らない。** 携帯ではパネルが下、PC では
左に居るので、そのぶんと二重になってボタンが浮き上がる。ビューの中だけで使う
`--vsab` / `--vsal` を `#view` に別に立ててある（パネルを畳んだときと閲覧モードでは
ビューが端まで届くので、そのときは元に戻る）。

**パネルは `padding-bottom` で受ける。** 背景は画面の端まで届かせたまま、中身だけ
ホームバーより上に来る。`#sheet` ではなく `#panel` に置くこと — `#sheet` は
`zoom:.78` の中なので、余白まで 0.78 倍される。

`env()` の値は Chromium のデスクトップでは常に 0 なので、**テストは変数を差し込んで
配線だけ見ている**（どの要素が変数を使っているか）。実際のノッチ避けは実機で。

### 指のためのつまみと文字

- **スライダーは `appearance:none` で自前の太さにしてある**（つまみ 28 px、高さ 48 px。
  `#sheet` は `zoom:.78` なので実際は 7〜8 割）。既定の細い線は指で掴めなかった（寺村さんの指摘）。
- **小さな画面では寸法ラベルを 7 割にする**（`@media (max-width:760px)` の `#labels span`）。
  重なり判定の 1 文字幅と行高も `drawLabels()` が同じ比で渡す。用紙は別の数字なので変わらない。
- `+`（「オブジェクトを追加」）の一覧の小道具と機材は明るい下地（`.people.props img`）。暗いテーマだと
  カメラとライトが黒く沈んで見えなかった。人物は下地なし。

### 拡大縮小は「指（カーソル）の下」を軸に

`zoomAt(mx, my, apply)` を通す。画面の真ん中を軸にすると、端をつまんだ瞬間に
見ていたところが枠の外へ逃げていき、**スマホでは狙ったところを拡大できない**。
つまむ操作もホイールも同じ関数を通している。

**2 本目の指が来たら長押しを取り消すこと**（`cancelLongPress()`）。これが無いと
550 ms でコンテキストメニューが開き、`pointers.clear()` でつまむ操作が丸ごと
消える。「スマホで拡大縮小がうまくできない」の正体はこれだった。

### 一覧のホバーは、組み直した直後は切る

行を消すと下の行が繰り上がり、**カーソルの下に来ただけの別の行のゴミ箱が赤くなる**。
「関係ない行が消える寸前」に見えるし、指で触る端末では触ったあとずっと赤いままになる。
`renderList()` / `renderCuts()` の最後で `suppressHover()`（`body.nohover`）を立て、
**指かカーソルが動いてから**効かせる。ホバーの規則そのものも
`@media (hover: hover)` の中に入れてある。

### ロック・複製・並べ替え・名前

右クリック（スマホは 550 ms の長押し）で「名前を変更／ロック／複製／削除」。
リストの行にもロックとゴミ箱のボタンがあり、左のつまみを掴むと並べ替えられる。

**指だけの端末には `contextmenu` が来ない。** iOS Safari は投げないので、一覧の行を
長押ししても何も出ず、代わりに文字選択が始まっていた（キャンバスの上だけは
`armLongPress` で自前に出していた）。行にも同じ 550 ms の長押しを付けてある
（`bindLongPress`）。オブジェクトの一覧もカットの一覧も、**名前のボタンにだけ**
付ける — ロックや目やゴミ箱を長押ししてメニューが出ると誤操作になる。
つまみ（並べ替え）は `pointerdown` で `stopPropagation` しているので届かない。

- **8 px 動いたら取り消す。** パネルはスクロールするし、つまみは並べ替えに使う。
- **マウスには効かせない**（`pointerType === 'mouse'` は素通し）。右クリックがある。
- **Android は長押しで `contextmenu` も投げる。** 来たらこちらのタイマーを取り消して、
  二重に開かないようにする。
- **`ctxGuard()` を通すこと。** メニューは指の真下に出るので、そのまま指を離すと
  その `click` が 1 行目（「名前を変更」）を押してしまう。出た直後の 350 ms だけ
  `pointer-events:none` にして、その 1 回を下へ逃がす。キャンバスの長押しも同じ。
並び順は「カメラ 1／カメラ 2」の番号にそのまま出るので、ただの見た目ではない。

名前は `it.label`。付けると `itemName()` も寸法ラベルの頭も差し替わる。
**リストには名前しか出さない**（身長や寸法は設定パネルとビューの寸法表示にある）。
設定パネルの一番下にあった「削除」も、行のゴミ箱と重複するので外した。

**`#ctx` の `display` は id 指定なので `[hidden]{display:none}` に勝つ。**
`#ctx[hidden]{display:none}` を必ず添えること。これが無いと、空のメニューが
前に開いた場所に小さな棒として貼り付き、「画面に黒い棒が出る」と報告される
（Artifact 側のひな型は `!important` 付きの `[hidden]` を持っているので、
プレビューでは再現しない。単体の `index.html` でだけ出る）。

`it.locked` が立っているものは**マニピュレータが出ず、ドラッグでも Delete でも
動かない**。選択と設定パネルからの編集はできる（でないとロックを外せない）。
