# LP（/about/）

`CLAUDE.md` から分けた機能ごとのメモ。**規則と同じ効力を持つ。** この領域を触る前に読み、分かったことはここに書き足す。

### 置き場所と狙い（v1.45.0〜）

寺村さんの「機能は成熟してきたが、使ってみないと魅力が伝わらない。LP を用意したい」。
**https://sp.taichi-teramura.com/about/**（同じサイトの中。`about/index.html` の 1 枚）。アプリ本体（`/`）は配った共有リンクと
QR が全部指しているので動かせない。同じリポジトリなので `tools/collect-site.sh` がそのまま拾い、ベータにも `/beta/about/` が出る。

- **1 枚の静的ページ。文章は寺村さんが書いたもの（v1.45.3〜）。** 見出し「撮影プランを、気軽に、簡単に。」→ 2 行の説明 →
  「Studio Plannerを使う」→ **ヒーロー画像は打合せの写真（`meeting.jpg`）**で、その下に「打ち合わせを、もっと分かりやすく。」の 3 行
  （v1.45.4、寺村さんの指示。v1.45.1〜1.45.3 は動画がヒーローだった）→ 紹介動画（YouTube `pjHt0Eg4Tx4`、`youtube-nocookie.com` の
  埋め込み）→ 6 つの節を絵と文で交互に（この広さで足りる？／背景はどこまで？／人物や機材も配置／ロケ地を持ち帰って検討／
  プランをそのまま資料に／PC・タブレット・スマホ）→ もう一度ボタン → フッター。よくある質問と料金の節は無い。
- **文章の方針（寺村さんの指摘、v1.45.1 と v1.45.3）。** 「CG スタッフではなく現場の人のために」のような開発時の想いは書かない。
  **文は少なく。** 想像すれば分かることは書かない。全機能を具体例で説明しない。節は「問いかけの見出し + 2 行」まで。
  **文章を直すときは寺村さんに書いてもらうか、書いた文をそのまま使う。** こちらで言い換えたり足したりしない。
  日本語と ASCII の間に空白を入れない（「Studio Plannerは」「GLB / FBX形式」）のも寺村さんの書き方なので合わせる。
- **見た目はアプリと同じ色の変数**（`--bg` `--panel` `--accent` …。ダーク対応も同じ 2 段の書き方）。書体も同じ Noto Sans JP。
- **英語はアプリと同じ流儀**: ブラウザが日本語でなければ英語、`?eng` で強制、`?lang=ja` で日本語。ただし辞書方式ではなく、
  要素ごとに `data-en`（`alt` は `data-en-alt`）に英文を持ち、起動時に差し替える。`html.lang`・`title`・description も切り替え、
  「使ってみる」のリンクには `?eng` を付ける。**新しい文言を足したら `data-en` も付ける**（ブロック 49 が `?eng` で日本語の
  残りを探す。言語の切替リンクの「日本語」だけは除外）。
- **絵は 7 枚。** `plan.jpg`・`finder.jpg`・`mobile.jpg` の 3 枚は `tools/make-about-shots.mjs` で焼く（`cd test && node ../tools/make-about-shots.mjs`。
  同じ配置（人 3・椅子・車・ライト 2・背景布・カメラ 32 mm）を組み、`#gl` の真ん中を 1200 × 800、スマホは 390 × 700 の 2 倍。
  `+` ボタンと小窓は `visibility:hidden` にしてから撮る。`window.__sp.orbit` は状態のオブジェクトで関数ではない）。
  `meeting.jpg`（打合せの席）・`sheet.jpg`（用紙の画面）・`scan.jpg`（洋館の 3DGS に車と男性）・`pose.jpg`（バレエの写真とポーズが
  乗った女性）の 4 枚は寺村さんが用意した実物で、**道具は触らない**。差し替えは寺村さんから受け取る。webp で届いたら
  `sharp` が無いので Playwright の canvas で JPEG（q86、幅 1600 まで）にする。
  v1.45.2 で使ったライト・`+` の一覧・スキャン中のスマホ・ファイル App の 4 枚は v1.45.3 で外した（履歴には残っている）。
- **訪問数の計測（Cloudflare の beacon）は LP にも入れてある。** アプリと同じトークンで、path が `/about/` になる。
- **アプリからのリンク**は「保存・共有」タブのコロフォンの下、`#aboutlink`（「Studio Planner について」、`about/`、別タブ）。
  `.colophon` の外（ブロック 28d はコロフォンが 1 行であることを見ている）。**1 枚の HTML や `file://` からは `about/` が
  無いので、起動時に公開先の絶対 URL に差し替える**（英語なら `?eng` 付き）。`EN` に `'Studio Planner について'` を足してある。
- Service Worker は `/about/` を控えない（圏外で LP は要らない）。圏外で `/about/` を開くとアプリ本体の控えが出るが、
  それは navigate の既定の落とし先で、LP のための挙動ではない。
