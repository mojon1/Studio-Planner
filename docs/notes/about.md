# LP（/about/）

`CLAUDE.md` から分けた機能ごとのメモ。**規則と同じ効力を持つ。** この領域を触る前に読み、分かったことはここに書き足す。

### 置き場所と狙い（v1.45.0〜）

寺村さんの「機能は成熟してきたが、使ってみないと魅力が伝わらない。LP を用意したい」。
**https://sp.taichi-teramura.com/about/**（同じサイトの中。`about/index.html` の 1 枚）。アプリ本体（`/`）は配った共有リンクと
QR が全部指しているので動かせない。同じリポジトリなので `tools/collect-site.sh` がそのまま拾い、ベータにも `/beta/about/` が出る。

- **1 枚の静的ページ。** 見出し（1 文）→ 使ってみる → **紹介動画がヒーロー**（YouTube `pjHt0Eg4Tx4`、`youtube-nocookie.com` の埋め込み。
  v1.45.1 から。それまでは 3D の画面写真だった）→ 機能の説明を絵と文で交互に（スタジオを作る／カメラの目で見る／人物とポーズ／
  ライトと小道具／ロケ地のスキャンとカット／用紙・リンク・QR／スマホ）→ 料金とデータ → よくある質問 → 最後にもう一度「使ってみる」→ フッター。
- **文の書き方（v1.45.1、寺村さんの指摘）。** 「CG スタッフではなく現場の人のために」の節は外した。開発時の想いであって、
  現場の人が知りたい情報ではない。それと「AI 臭い」文にしない: **硬い言い回しをしない、体言止めを続けない、同じ話を
  言い換えて何度も書かない。** 本文は「です・ます」の完結した文で、1 つの機能は 1 か所にだけ書く（「登録なし」は冒頭と
  料金の節だけ、など）。見出しは短くてよい。
- **見た目はアプリと同じ色の変数**（`--bg` `--panel` `--accent` …。ダーク対応も同じ 2 段の書き方）。書体も同じ Noto Sans JP。
- **英語はアプリと同じ流儀**: ブラウザが日本語でなければ英語、`?eng` で強制、`?lang=ja` で日本語。ただし辞書方式ではなく、
  要素ごとに `data-en`（`alt` は `data-en-alt`）に英文を持ち、起動時に差し替える。`html.lang`・`title`・description も切り替え、
  「使ってみる」のリンクには `?eng` を付ける。**新しい文言を足したら `data-en` も付ける**（ブロック 49 が `?eng` で日本語の
  残りを探す。言語の切替リンクの「日本語」だけは除外）。
- **絵は `tools/make-about-shots.mjs` で焼く**（`cd test && node ../tools/make-about-shots.mjs`）。同じ配置（人 3・椅子・車・ライト 2・
  背景布・カメラ 32 mm）を組んで、上面・ファインダー・ライト（3D で寄って環境光を落とし、光と影が主役の角度。`#gl` の真ん中を
  1200 × 800）・A4 の用紙（PDF の画面の 1 ページ目）・スマホ（390 × 700 の 2 倍）・`+` の人物一覧（`#people` を 2 倍で）の
  6 枚を JPEG（q84〜86、40〜90 KB）で `about/img/` に。PC の絵は `+` ボタンと小窓を `visibility:hidden` にしてから撮る。
  `window.__sp.orbit` は状態のオブジェクト（`theta` `phi` `radius`）で関数ではないので、視点は代入で決める。
  人物モデルは 3 体とも読み終わるのを待ってから撮る。ヘッドレスの swiftshader なので影は実機よりぼんやりしている。
- **寺村さんに用意してもらう絵（未着）。** 手持ちの画面写真だけで組まず、実物の写真を差し込む。欲しいものは v1.45.1 の
  報告で伝えてある（現場で iPad を見ている写真、本物のロケ地スキャンの画面、印刷した用紙、写真ポーズ指定の元写真と結果の並び、
  図面と実際に撮れた絵の並び）。届いたら `about/img/` に置いて該当の節に差し替える。
- **訪問数の計測（Cloudflare の beacon）は LP にも入れてある。** アプリと同じトークンで、path が `/about/` になる。
- **アプリからのリンク**は「保存・共有」タブのコロフォンの下、`#aboutlink`（「Studio Planner について」、`about/`、別タブ）。
  `.colophon` の外（ブロック 28d はコロフォンが 1 行であることを見ている）。**1 枚の HTML や `file://` からは `about/` が
  無いので、起動時に公開先の絶対 URL に差し替える**（英語なら `?eng` 付き）。`EN` に `'Studio Planner について'` を足してある。
- Service Worker は `/about/` を控えない（圏外で LP は要らない）。圏外で `/about/` を開くとアプリ本体の控えが出るが、
  それは navigate の既定の落とし先で、LP のための挙動ではない。
