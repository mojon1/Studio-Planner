# Studio Planner

スタジオ撮影の準備と打合せのための 3D Web アプリ。ブラウザだけで動き、
スマホとタブレットでも操作できる。インストールもログインも不要。無料。

**→ https://mojon1.github.io/Studio-Planner/**

CG スタッフではなく、プロダクションマネージャー・カメラマン・照明チーム・
ディレクターが、現場で 30 秒で答えを得るための道具として作っている。

![Studio Planner](ogp.png)

- 開発用プレビュー（人物モデルは出ません）: https://claude.ai/code/artifact/85c9a190-9e05-4b34-b66b-d4692507d6f9

## できること

| 分類 | 内容 |
|---|---|
| スタジオ | 幅・奥行・高さの入力、プリセット 4 種、ホリゾント（R 壁）を奥・左・右で個別に指定 |
| 人物モデル | 実写風の人物 14 体（大人 12 体＝アジア系・アフリカ系・欧米系 × スーツ・カジュアル × 男女、子ども 2 体＝男の子・女の子）。`+` から顔で選ぶ。身長スライダーに追従 |
| ポーズ | 立つ 3・座る 2・寝る 2 の 7 種。人物の設定パネルの一番下からサムネイルで選ぶ。**「写真ポーズ指定」**で写真の人の姿勢をそのまま写せる（スマホならその場で撮って）。ブラウザの中だけで推定するので、写真はどこにも送られない |
| 小道具 | 車、椅子、テーブル（角・丸）、箱。すべて寸法可変。箱馬は 300×450×150 mm 固定で、平・横・縦に置き分け。箱・箱馬・テーブルの上には物を載せられ、箱馬どうしは積める |
| 車 | 実物を写した 3D モデル 2 種（セダン・SUV）。サムネイルで選ぶと実車の寸法が入る。全長・全幅・全高は現物に合わせて動かせる。窓がガラスのモデルなら車内にカメラを置いてガラス越しの画も見られる |
| 撮影機材 | カメラ（複数可・見ている 1 台を切替）、ライト、ミラー（床鏡・立て鏡）、背景布（色自由）、定規（画面を 2 回タップして始点と終点。端をドラッグで直せる。3DGS の上にも置ける） |
| 環境光 | スタジオの設定に 0〜100 のつまみ。ライトを置くと自動で暗くなり（50 → 25）、手でも動かせる。0 で真っ暗。3D とファインダーに効く |
| 取り込み | GLB / FBX（1 個 120MB まで）と 3DGS のスキャン .spz / .ply（1 個 240MB まで）。ドラッグ&ドロップ対応。単位の自動判定と横倒し補正つき。3DGS は向き・傾き（前後・左右）をワールド軸まわりで回せ、軸の位置で回転の中心を選べる。高さは ±50 m |
| ロケーション | Scaniverse などで撮った **3D ガウシアンスプラッティング（.spz / .ply）** を取り込んで、その現場の中で撮影計画を立てられる。スタジオは消せる。要らない範囲は**箱で切り取れる** |
| ビュー | 上面 / 側面 / 正面 / 3D / カメラ全画面。カメラ窓は移動とサイズ変更ができ、**別ウィンドウに切り離してサブモニタへ出せる**（スマホ・タブレットを除く）。グリッドと寸法は個別に消せる |
| カメラ | 高さ・パン・チルト・ロール。センサーはフォーマット選択（スーパー35・フルサイズ・MFT・手動）、焦点距離、比率（プリセットと手動の横：縦）。チルトは図面上の弧でも動かせる |
| 画面 | 中ボタンか右ボタンのドラッグ、または 2 本指のスワイプで画面を動かせる。動かすと「中心に戻す」が出る |
| カメラの小窓 | 右下の目のボタンで開閉。小窓はカメラの画面比率そのものの形になる（9:16 なら縦長）。バーの「別ウィンドウで開く」で切り離せる（PC のみ。そちらは余白付き） |
| 英語表示 | ブラウザの言語が日本語でなければ自動で英語。URL に `?eng` を付けると強制的に英語 |
| 座る | 椅子のポーズの人を椅子や箱に重ねるとお尻が座面に吸着し、座面を上げれば一緒に上がる。立つポーズなら天面の上に立つ |
| 編集 | ドラッグで移動、リングで回転。右クリック（スマホは長押し）で削除・複製・ロック。背景布・鏡・箱・テーブルは角をつまんで大きさ変更（箱とテーブルは天面の真ん中で高さ、カメラは頭の上のつまみで高さ）。取り消し／やり直し（Ctrl+Z / Ctrl+Shift+Z） |
| カット | 1 つの案件に複数カット。「カット」タブで切り替え・複製・新規・並べ替え。カット名とメモもここ |
| リスト | 表示の切替、ロック、削除、つまみを掴んで並べ替え。名前は右クリックから変更 |
| 共有 | 配置を URL に圧縮して埋め込む。サーバー不要。QR コードでその場のスマホへ渡せる。図面とカメラ絵を PNG 書き出し |
| オフライン | ホーム画面に置いてアプリのように起動できる。一度使ったものは端末に残るので、圏外でもそのまま開く |
| 3Dデータ書き出し（GLB） | シーンとカメラを **GLB** で書き出す。テクスチャごと 1 ファイル、単位はメートル。Blender でも Cinema 4D でも開ける。カメラは向きも画角もそのまま（焦点距離とセンサー幅は glTF が持てないので画角だけ）。三脚は入るがカメラ本体は入らない（向こうに本物のカメラが立つため）。3DGS は入らない |
| HTML書き出し | **外部3Dデータと人物・車のモデルをすべて含めた 1 枚の HTML** として書き出す。**オフラインの PC** で開けて、その場で人や車を足せる（素の状態で 28.5 MB ほど）。中から出す共有リンクと QR は Web の URL になる。**iPhone / iPad では開けない** — iOS は `file://` の HTML を実行できないので、そちらの圏外対策はホーム画面への追加（Service Worker）で |
| PDF | A4 一枚に図とカメラ情報。載せる図は上面・側面・正面・3D・ファインダーから選択（枚数に応じて割り付けが変わる）。用紙の向き・タイトル・範囲は「PDF資料作成」を押したあとの画面で選ぶ。全カットならカットごとに 1 枚 |

## 保存と共有の使い分け

| したいこと | 使うもの |
|---|---|
| いま画面を見せたい・チャットに貼りたい | 「共有リンク」 |
| 来月また開きたい・PC を移したい | 「HTML書き出し」（1 枚で完結。外部3Dデータも入ります）|
| 目の前の人のスマホで開いてほしい | 「共有QRコード」（読み取ってもらうだけ） |
| 現場が圏外かもしれない・相手に丸ごと渡したい | 「HTML書き出し」（1 枚の HTML。モデルもスキャンも入ります） |

取り込んだ 3D モデルと 3DGS のスキャンの実体は、その端末の中だけに残る。
リンクには名前と実寸しか入らないので、別の PC で開くと実寸の箱として出る。
**実体ごと渡したいときは「HTML書き出し」**。

## PDF の作り方

「カット」タブでカット名とメモを入れ、「保存・共有」タブで「PDF資料作成」。
表示された画面で用紙の向き・載せる図・タイトル・範囲を選び、用紙を確認してから
「PDF にする」を押し、ブラウザの印刷画面で送信先を「PDF に保存」にする。
用紙の中の図はドラッグで動かし、ホイールで拡大縮小できる。ファインダーだけは
動かせない。カメラが実際に撮る画角とずれた絵を配ることになるため、意図的に固定してある。

日本語を確実に出すためにブラウザの印刷機能を使っている。jsPDF などで直接
書き出す場合、CJK フォントを数 MB 埋め込む必要があり、単一 HTML の構成と合わない。

## 動かし方

**`file://` で直接開くと動きません。** ES モジュールと importmap を使っているため、
必ず HTTP で配信すること。

```
python -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開く。Node があるなら `npx serve` でもよい。

## 公開の仕方

`main` に push すると GitHub Actions が GitHub Pages へ出す。ビルドは無い。

```
https://mojon1.github.io/Studio-Planner/
```

**最初の 1 回だけ手作業がいる。** リポジトリの Settings → Pages →
Build and deployment → Source を「**GitHub Actions**」にする。
GITHUB_TOKEN には Pages サイトを新規作成する権限が無いため、ここは自動化できない。
入れたら Actions タブの「Deploy to GitHub Pages」を Re-run。以降は push で出る。

出すのは `index.html` / `models/` / `ogp.png` / `manifest.webmanifest` / `sw.js` /
`icon-*.png` / `README.md` だけ。
`test/` `tools/` `docs/` `CLAUDE.md` は除いてある。

帯域が足りなくなったり独自ドメインを付けたくなったら Cloudflare Pages に
移せる（このリポジトリを繋ぐだけ。無料枠は帯域無制限、1 ファイル 25 MiB まで）。

### OGP 画像

リンクを貼ったときのサムネイルは `ogp.png`。アプリ自身をヘッドレスで撮っている。

```
cd test && npm install
PW_CHROME=<chromium> node ../tools/make-ogp.mjs
```

UI を変えたら撮り直す。`index.html` の `og:image` は絶対 URL なので、
独自ドメインに移すときはそこも直す。

### アイコン

ホーム画面のアイコンは favicon と同じ絵柄を焼いたもの。

```
cd test && npm install
PW_CHROME=<chromium> node ../tools/make-icons.mjs
```

## テスト

`test/` にヘッドレスブラウザでの動作確認スクリプトがある。

```
cd test
npm install
node run.mjs
```

スクリーンショットが `test/out/` に出る。JS エラーの有無、共有リンクの往復、
モデル取り込みの寸法、センサー換算値などを確認できる。

## オフラインで使う

スマホのブラウザで開き、共有メニューから「ホーム画面に追加」。アイコンから
起動するとブラウザの枠が消え、ふつうのアプリのように出る（ノッチとホームバーは
自動で避ける）。

圏外でも、**一度開いた端末はそのまま開く**（Service Worker が控えを持つ）。置いた
人物や車のモデルも、一度出したものは残る。共有リンクは URL の中に配置が入っているので、
リンクさえ手元にあれば通信なしで開ける。

確実に持ち出したいときは「保存・共有」タブの**「まとめて書き出す」**。アプリ本体・
three・部品・置いたモデル・ロケーションのスキャン・配置を、**1 枚の HTML** に詰めて
書き出す。ダブルクリックで開き、通信は 1 本も出さない。相手に渡すのもこれ 1 つで済む
（リンクや「保存」のファイルと違って、モデルとスキャンの実体が入っている）。

- 大きさは中身しだい。3DGS のスキャンを 1 つ入れると 20 MB ほどになる。
- Google Fonts は外してあるので、書体は端末のものになる。
- Draco / KTX2 で圧縮された取り込みモデルだけは、展開部品を通信で取りに行くので開けない。

## 技術的なメモ

- three.js r180 を jsDelivr から importmap で読み込む。ビルドツールは使わない。
- 3DGS は [Spark](https://github.com/sparkjsdev/spark)（MIT）。three 本体の 3DGS は
  WebGPU 専用なので、WebGLRenderer のまま使えるこちらを採用した。**5 MB あるので、
  スキャンを置いた人のときだけ取りに行く。**
- オフラインは Service Worker（`sw.js`）。`index.html` はネットワーク優先で、
  圏外のときだけ控えを出す（古い版が焼き付かないように）。`sw.js` を直したら
  `VERSION` を上げること。
- QR コードは外部ライブラリを使わず `index.html` の中で組み立てている
  （バイトモード・誤り訂正 L・型 1〜40）。テストで npm の `qrcode` と
  1 モジュールずつ突き合わせ、`jsQR` で実際に読ませて確かめている。
- 取り消しは state の JSON を丸ごと積むだけ。60 手まで。
- **英語表示**: ブラウザの言語が日本語でなければ自動で英語になる。設定は無い。
  URL に `?eng` を付けると日本語のブラウザでも英語で開く（`?lang=ja` で日本語）。
  ソースの文字列は日本語のままで、画面に出た文字を辞書で差し替えている。
- 写真ポーズ指定は Google の [MediaPipe Pose Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/pose_landmarker)
  をブラウザの中で動かす。wasm（12 MB）は jsDelivr、モデル（9.4 MB）は `models/` に同梱。
  **押した人だけが初回に取りに行き**、一度取れば圏外でも動く。写真は端末の外に出ない。
  奥行きは 1 枚の写真からの推定なので目安。
- **窓を透過させたい 3D モデルは、窓のマテリアルを分けて名前に `glass` か
  `ガラス` を入れて書き出す**（または alphaMode を BLEND にして不透明度を落とす）。
  同梱の車も取り込んだモデルも同じ扱い。マテリアルが分かれていないモデルは、
  中にカメラを置くと画面が真っ黒になるだけなので、そのカメラの絵からは外す。
- 人物モデルは `models/` の GLB。「人物」に切り替えたときだけ取りに行くので、
  使わない人は 1 バイトも払わない。**`file://` や claude.ai のプレビュー枠では
  取りに行けず、マネキンのままになる。**
- 取り込んだ 3D モデルの実体は IndexedDB にその端末だけで保存する。
  共有リンクには名前・実寸・位置だけが入り、相手の画面では実寸の箱になる。
- DRACO / KTX2 で圧縮した glTF は、デコーダを実行時に外部から取りに行くため
  Artifact の通信制限下では読めない。自前のサーバーに置けば動く。非圧縮の GLB 推奨。
- カメラ窓の位置とサイズ、設定パネルの開閉、保存したセンサー幅は localStorage に入る。
